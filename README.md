# EV Charging App ⚡

## Project Overview
A mobile-first UI/UX design project focused on making EV charging easier and more convenient.

## Problem Statement
EV drivers may struggle to find charging stations, estimate waiting times, and get assistance when their vehicle battery is low.

## Key Features
- Charging station discovery
- AI-powered battery range prediction
- Charging queue prediction
- 24/7 EV rescue assistance
- Battery health dashboard

## Design Goals
- Make charging stations easier to find
- Help users plan charging stops
- Provide clear battery and charging information

## Tools Used
- Figma
- Wireframing
- Prototyping
- UI/UX Design
